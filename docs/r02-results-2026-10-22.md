## Trace, reproduction and selected fixes

Each area followed source/evidence tracing, a stated fault/probe plan, disposable reproduction, a scoped change where needed, and validation. The original plan remains historical; the execution results below supersede its planning-only status.

| Boundary | Reproduced result / existing guard | Resulting change |
| --- | --- | --- |
| Background job/benchmark persistence | Injected SQLite errors escaped progress, terminal and benchmark writes. A shutdown write error prevented worker cleanup. | `backend/jobs.py` retains the latest unsaved job and one benchmark result, retries at two-second intervals, and keeps the listener alive. New generation/benchmark work is blocked until pending writes succeed. Cleanup runs even when final persistence fails. Idle policy reads also handle storage errors without ending the listener. |
| Truthful pending state | Terminal metadata can remain unsaved although audio production has finished. | `backend/bridge.py` exposes a recovery warning and the latest pending job; an uncommitted completion is displayed as assembling rather than ready. Pending playback-position updates are retained. Warning clears after persistence succeeds. |
| Export replacement | Injected partial copy damaged the previous destination or published a new partial destination. A final-replace failure was not separately protected. | Copy to an exclusive temporary file beside the destination, flush with `fsync`, then replace only after a successful copy. Failure preserves source/previous destination and removes only the owned temporary file where possible. This is not a physical power-loss guarantee. |
| Invalid row plus failed recovery bookkeeping | A failed quarantine INSERT prevented healthy documents from loading. | `backend/storage.py` retains original rows, reports a bounded recovery warning, and permits healthy rows to load when only recovery bookkeeping cannot be written. This does not make an unreadable database readable. |
| Worker output/cache failures | Job-directory creation could escape the per-job handler; optional cache initialization/read/write errors could stop otherwise usable generation. | `backend/speech.py` reports required output failures through the job error path and remains available for the next command. Optional cache I/O failure disables reuse for that job and continues generation. Failed final assembly already preserved published section bytes; that guard was retained. |
| Whole-file database damage | A synthetic non-SQLite file caused startup failure without changing its bytes. | Existing non-destructive guard retained. No reset, deletion, automatic repair or full recovery UI added. |
| Canceled native navigation and close | After controlled canceled navigation, the document/bridge could appear usable while the latest close-time edit timed out. The pinned pywebview 6.2.1 backend reinjects its JS bridge on canceled NavigationCompleted events, resetting in-flight callback tables. A focused regression failed before the adapter. | `backend/desktop.py` wraps the process-local completion handler: skip reinjection only for OperationCanceled when the original trusted page remains. Real loads and other failures retain normal initialization. Vendor files, CSP, navigation allowlists and public dispatch permissions are unchanged. |

The persistence queue is bounded to one latest job and one benchmark result; it does not accumulate every progress event. Failed background writes are logged once per failure episode. **Unsaved metadata remains in memory until a write succeeds. Closing/forcing exit while storage remains unavailable can lose that latest metadata; earlier durable snapshots and saved audio are retained.** These changes do not promise that an unavailable disk can save data.

## Navigation and local-resource assessment

The final debug-off native probe exercised `location.href`, `assign`, `replace`, native Navigate and CDP navigation to a controlled second loopback origin, plus a frame attempt. It inspected native Source, original document identity/DOM, fresh and previously held API references, an actual UI action, and save-on-close followed by reopening SQLite. The final run passed, including the newest edit saved after navigation attempts.

Canceled navigation is **not a zero-network guarantee**. Five preliminary GETs reached the controlled destination, with no Referer or Cookie observed in these requests; the foreign page's script marker was not requested, and its attempted native settings mutation did not occur. Microsoft's [NavigationStartingEventArgs documentation](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2navigationstartingeventargs) explicitly allows preliminary network requests before cancellation takes effect. Carry this limitation into privacy claims. The probe does not establish that arbitrary destinations can never receive other request metadata.

The historical body-locator timeout is not conclusively assigned a root cause. Current CDP body observation passed, while the new probe independently reproduced and fixed a concrete canceled-navigation/save-callback failure. Earlier failed runs are retained rather than relabeled as passes.

Synthetic media checks passed app-origin fetch/playback, raw GET/HEAD/Range and published-section access. Unknown IDs/unpublished sections returned 404, invalid Host/traversal returned 403 and POST returned 501. Controlled foreign-origin fetch could not read the response, valid audio embedding was blocked, and framing failed. Media responses retained no CORS grant, same-origin resource protection and denied framing.

**A raw local client that knows the port and recording UUID can still retrieve audio.** The tested browser isolation does not establish authentication or cross-user Windows isolation. No ordinary tested flow exposed a recording UUID through foreign page execution. Based on this scoped result, session binding remains optional hardening rather than an automatic R-02 feature. Installed ACL/custom/shared-folder review stays open; no personal AppData or user library was inspected.
